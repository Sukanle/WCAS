# 安全策略

`WCAS` 是安全敏感的基础设施。它代理显示协议并合成输入，因此涉及认证、协议过滤、进程归属或清理的改动需要显式安全评审。

## 支持的版本

项目处于实验期，仅支持最新的 `0.1.x` 版本。在 `1.0` 之前，安全修复可能包含破坏性 API 变更。

## 报告漏洞

未公开的漏洞请勿开公开 issue。请使用本仓库的 GitHub 私密漏洞报告或 Security Advisory 功能。请附：

- 受影响版本与 Linux 发行版；
- 合成器与 toolkit；
- 复现步骤或 PoC；
- 观察到的进程、socket、文件权限或跨应用影响。

## 信任模型

本库假设：

- harness 与被控应用运行在同一受信任的 Unix 用户下；
- harness 是有意选择它所启动的可执行文件；
- 宿主合成器、内核、XWayland 与第三方依赖受信任；
- harness 继承的环境变量是受信任的配置。

本库不对被控应用做沙箱隔离。除非嵌入的 harness 另行提供沙箱，该应用仍拥有用户的文件系统、网络、D-Bus 等操作系统权限。

## 安全不变量

- 仅接受同 UID 对端，依据内核 `SO_PEERCRED`。
- 私有 Wayland socket 权限为 `0600`。
- 绝不广播特权（跨客户端）Wayland 接口。
- 不实现环境级全桌面捕获。
- XWayland 使用高熵 MIT-MAGIC-COOKIE、`0600` 的 Xauthority、`0700` 的运行时目录与 `-nolisten tcp`。
- 受控子进程接收父死信号，并被显式回收。
- 每个临时路径都是精确、私有、且在其属主退出后删除的。
- 关闭是幂等的，并在 join worker 与桥线程之前关闭活动代理连接。

任何削弱不变量的改动都需要附上威胁模型更新。

## 非目标

- 安全执行恶意或不受信任的应用。
- 绕过合成器去控制非调用方启动的应用。
- 对桌面用户隐藏被控应用。
- 替代 Flatpak、Bubblewrap、容器、seccomp 或操作系统权限模型。
